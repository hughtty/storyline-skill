# character-manager

管理教育项目剧情角色的子技能，负责角色档案的创建、读取、一致性检查和跨学科适配。

## 核心职责

1. **角色档案管理**：创建和维护角色的结构化 Markdown 档案
2. **角色库维护**：管理总角色库（master_library）和项目级覆盖
3. **一致性检查**：确保同一角色在不同学科故事中性格一致
4. **跨学科适配**：允许微小差异，禁止巨大变动（除非用户主动要求）

## 角色档案模板

每个角色一个 Markdown 文件，路径：`shared_library/characters/{ip|npc}/{character_id}.md`

```markdown
---
name: 角色名称
type: ip | npc
subjects: [学科列表]
frequency: 主角 | 配角 | 路人
created_at: YYYY-MM-DD
updated_at: YYYY-MM-DD
---
```

## 关键规则

1. **性格一致性**：同一角色的"核心性格"字段不可擅自修改
2. **修改机制**：用户主动要求修改时，创建项目级覆盖文件，保留原档案
3. **跨学科差异**：仅允许语言风格、知识领域相关的微调，不可改变性格本质
4. **复用优先**：新项目默认从总库加载角色，鼓励复用

## 接口

### 创建角色
输入：角色基本信息（名称、类型、性格、外貌、背景）
输出：角色档案文件路径

### 加载角色
输入：角色名称或项目ID
输出：角色档案内容 + 项目级覆盖（如有）

### 检查一致性
输入：角色名称 + 新场景描述
输出：一致性评估（通过 / 需调整 / 冲突）

### 列出角色
输入：项目ID（可选）、学科过滤（可选）
输出：角色列表及基本信息
