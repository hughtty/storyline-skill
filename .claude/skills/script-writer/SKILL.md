# script-writer

核心子技能，负责撰写完整的动画分镜脚本和教学节点对白。是整个 storyline-skill 中最关键的写作能力模块。

## 核心职责

1. **开场分镜脚本**：将故事梗概转化为详细的动画分镜（opening_storyboard.md）
2. **结尾分镜脚本**：撰写解决困境 + 下集预告的分镜（ending_storyboard.md）
3. **节点对白撰写**：为每个教学节点提供可直接使用的对白和动作描述（node_scripts.md）
4. **钩子融入叙事**：确保钩子自然融入剧情，不生硬、不突兀

## 能力维度

| 维度 | 要求 | 说明 |
|------|------|------|
| **分镜叙事** | 将剧情转化为镜头语言 | 明确景别、运镜、时长、画面描述 |
| **对白设计** | 符合角色性格 + 认知水平 | 低年级短句、口语化；高年级可复杂表达 |
| **钩子植入** | 自然融入，不生硬 | 困境与知识点的隐喻关联要巧妙 |
| **节奏控制** | 1-2 分钟动画的叙事节奏 | 开场→发展→小高潮，张弛有度 |
| **视觉化思维** | 文字要能指导动画制作 | 具体的画面动作、表情、特效描述 |
| **教学融合** | 剧情即知识点的隐喻 | 困境=待解问题，钥匙=知识点 |

## 写作原则

### 分镜脚本
1. **景别明确**：每个镜头必须标注景别
2. **时长精确**：每个镜头标注预计秒数，总时长控制在 1-2 分钟
3. **画面可执行**：描述要具体，动画老师能直接理解要画什么
4. **对白简洁**：动画中的对白要短，信息密度高

### 对白设计
1. **符合角色性格**：每个角色的台词风格要与其档案一致
2. **认知水平适配**：
   - 低年级（1-3）：简单句、重复强调、语气词多
   - 中年级（4-6）：适当复杂句、可含简单推理
   - 高年级（初中+）：复杂表达、可含隐喻
3. **口语化**：避免书面语，像角色在说话
4. **信息功能**：每句台词要有明确功能（推进剧情/解释/情感表达）

### 钩子处理
1. **开场钩子**：通过角色困境自然抛出，不强行说教
2. **中间回收**：每个节点回收一小部分，有进度感
3. **结尾解决**：利用所学知识解决困境，有成就感
4. **下集预告**：如适用，结尾抛出与下节课知识点相关的新悬念
