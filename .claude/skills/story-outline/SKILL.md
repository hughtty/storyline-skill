# story-outline

生成教育项目课时故事梗概的子技能，是整个剧情创作流程的第一个创作节点。

## 核心职责

1. **知识点理解**：接收老师输入的核心知识点，自动搜索公开资料加深理解
2. **角色匹配**：从角色库中选取适合本课时的角色，分配任务
3. **钩子设计**：设计开场悬念钩子，确保与知识点紧密关联
4. **故事梗概生成**：输出结构化的故事梗概文档

## 工作流程

```
输入：学科、年级、核心知识点、课时类型、选用角色

Step 1: 知识点分析
  ├── 如需要，调用 web search 搜索公开资料
  ├── 理解知识点的定义、规则、典型场景
  └── 评估认知水平适配（根据年级或知识点难度）

Step 2: 角色任务分配
  ├── 从角色库加载选用角色
  ├── 分配角色在本课时中的功能（遭遇困境/引导/协助）
  └── 确认角色行为符合性格设定

Step 3: 钩子设计
  ├── 将知识点转化为角色困境/任务
  ├── 设计开场悬念（抛出钩子）
  └── 确保钩子能在中间教学节点中被逐步回收

Step 4: 生成梗概
  └── 输出结构化的 story_outline.md
```

## 输出格式

路径：`episodes/{episode_id}/story_outline.md`

```markdown

- 学科：
- 年级/认知水平：
- 核心知识点：
- 课时类型：主线 / 支线 / 跨课时（第 N 部分）
- 预计时长：开场 XX 秒 + 中间教学 + 结尾 XX 秒

## 一句话梗概
[用一句话概括本课时的故事]

## 角色任务分配
| 角色 | 任务 | 出场环节 |
|------|------|----------|

## 三幕结构摘要

### 第一幕：开场（动画）
- 场景：
- 角色遭遇的困境/任务：
- 【钩子】：抛出的悬念（与知识点的关联）：

### 第二幕：中间（教学穿插）
- 知识点如何转化为剧情推进力：
- 关键节点预览（简述）：

### 第三幕：结尾（动画）
- 困境如何解决：
- 【钩子回收】：如何利用所学解决开场问题
- 【下集预告】：（如适用）

## 教学抓手设计
| 知识点 | 剧情对应 | 抓手描述 |
|--------|----------|----------|

## 认知水平适配说明
- 台词风格：
- 情节复杂度：
- 人物关系：

## 待确认事项
- [ ] 故事方向是否符合预期？
- [ ] 角色分配是否合理？
- [ ] 钩子设计是否自然？
- [ ] 是否有需要调整的部分？
```

## 关键规则

1. **必须先确认**：梗概必须经用户确认后才能进入下一步
2. **知识点为核心**：所有剧情设计必须服务于知识点教学
3. **认知适配**：根据年级调整叙事复杂度
4. **钩子可落地**：设计的悬念必须在技术上能被中间教学节点回收
5. **自闭环**：单课时故事必须有完整的起承转合

## 接口

### 生成梗概
输入：学科、年级、知识点、课时类型、角色列表
输出：story_outline.md 文件路径

### 修改梗概
输入：修改意见
输出：更新后的 story_outline.md
