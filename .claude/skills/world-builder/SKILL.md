# world-builder

构建和维护教育项目世界观的子技能。

## 核心职责

1. **世界观文档创建**：为每个项目生成结构化的世界观 Markdown 文档
2. **世界观维护**：支持项目延续时的世界观更新
3. **一致性保障**：确保同一项目下所有课时的世界观不冲突
4. **跨项目复用**：提供世界观模板，支持新项目基于已有世界观扩展

## 关键规则

1. **单项目单世界观**：一个项目对应一个世界观文档
2. **延续性**：新项目可选择沿用已有世界观
3. **课时一致性**：所有课时故事必须遵守世界观设定
4. **渐进扩展**：允许在已有世界观基础上增加新场景、新规则

## 接口

### 创建世界观
输入：世界观描述（可由用户提供，或由 Skill 基于主题生成）
输出：世界观文档路径

### 加载世界观
输入：项目ID
输出：世界观文档内容

### 更新世界观
输入：项目ID + 更新内容
输出：更新后的世界观文档

### 验证一致性
输入：项目ID + 新场景/设定描述
输出：与现有世界观的一致性评估
