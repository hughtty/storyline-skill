# 结尾分镜脚本：被封印的魔法书

- 下集预告钩子设计："时间密室"暗示与"过去的时间"相关，为一般过去时的学习做铺垫

## 钩子回收说明
- 开场困境：三把锁需要说出"太阳升起、月亮落下、星星闪烁"的规律才能打开
- 如何解决：小智和小慧用一般现在时分别说出三个规律（The sun rises... / The moon goes down... / The stars shine...），三把锁依次打开
- 知识点在剧情中的具象化呈现：每个规律对应一把锁，锁的图案（太阳、月亮、星星）与规律内容直接对应，学生能直观看到"学会知识点 → 解决剧情困难"的因果关系
