# 小慧

## 基础设定

### 性格（核心，跨学科保持一致）
- 核心性格特征：聪明、谨慎、善于观察，有时过于担心而不敢行动
- 口头禅/标志性语言风格："等一下，让我想想...""根据我的分析...""小智，别冲动！"
- 情绪表达方式：内敛，通过推眼镜或整理头发表达紧张

### 外貌
- 形象描述：10岁女孩，黑色长辫，戴着一副圆框眼镜，眼神聪慧
- 标志性服饰/道具：蓝色魔法袍（比小智的披风正式多了），手持魔法笔记本

### 背景故事
- 来历：魔法世家出身，从小接受严格的语言教育
- 目标/动机：用知识守护世界和平，证明智慧比蛮力更重要

## 跨学科适配记录

### 默认状态（基线）
小慧是一个冷静理性的女孩，遇到问题会先分析再行动。她经常扮演"刹车片"的角色，阻止小智的冲动。但有时也会因为想太多而错失机会。

### 学科适配（仅允许微调）
- 英语课：擅长语法分析，但口语表达不够自信
- 数学课：逻辑能力最强，经常发现别人忽略的规律

- 该角色的核心驱动力是什么？用知识和智慧解决问题
