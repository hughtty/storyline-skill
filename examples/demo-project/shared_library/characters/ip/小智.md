# 小智

## 基础设定

### 性格（核心，跨学科保持一致）
- 核心性格特征：勇敢、正义感强，但有些莽撞，经常不思考就行动
- 口头禅/标志性语言风格："让我来！""这有什么难的！""哎呀，我又搞砸了..."
- 情绪表达方式：直接、外放，高兴就大笑，沮丧就低头

### 外貌
- 形象描述：10岁男孩，棕色短发，眼睛大而亮，总是充满活力
- 标志性服饰/道具：红色披风（自称是"勇者披风"），腰间挂着一本小字典

### 背景故事
- 来历：普通村庄的孩子，因为一次意外发现自己有语言魔法天赋
- 目标/动机：成为最伟大的语言魔法师，保护语言世界

## 跨学科适配记录

### 默认状态（基线）
小智是一个热血冲动的少年，遇到困难第一反应是冲上去，而不是思考。但在朋友们的帮助下，他学会了先理解再行动。

### 学科适配（仅允许微调）
- 英语课：对语法规则感到困惑，经常用错时态，但通过练习逐渐掌握
- 语文课：对古诗词感兴趣，但因为性子急经常读不懂深层含义
