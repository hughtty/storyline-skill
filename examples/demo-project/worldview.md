# 魔法英语学院 世界观

## 基础设定

### 世界名称
魔法英语学院（Magic English Academy）

### 时间背景
一个平行世界，在这里魔法的力量来自于对语言规律的掌握。

### 空间设定
- **主要场景**：魔法学院、魔法图书馆、咒语实验室、魔法森林
- **场景描述**：学院建筑融合了古典城堡与现代学院风格，到处漂浮着发光的字母和符号

### 核心规则
- 魔法能量 = 语言能力
- 咒语 = 正确的英语句子
- 魔法书封印 = 语法规则谜题
- 魔法道具激活 = 单词拼写正确
- **与知识点的隐喻关联**：所有魔法问题本质上都是语言问题

## 历史与背景

### 世界观时间线
- 很久以前：语言魔法被发明
- 100年前：魔法学院建立
- 现在：主角们入学，开始冒险

### 当前局势
- 主线任务背景：学院中发现古老的预言，需要找到"语言之心"
- 主要矛盾：理解语言规律 → 获得力量 → 解开预言
