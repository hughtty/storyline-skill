# 开场分镜脚本：证据的谎言

## 基本信息
- 时长：约 120 秒
- 场景：证据法庭（魔法学院最高审判厅）
- 出场角色：小智、小慧、老猫头鹰教授、小黑猫（背景中）、鹦鹉助手（背景中）、老乌龟管理员（背景中）
- 核心功能：引入困境 + 双层钩子（表层：谁偷了碎片？深层：为什么证据互相矛盾？）

## 钩子植入说明

### 表层钩子
- **内容**：谁偷了「语言之心」碎片？三个嫌疑人各有铁证，但证据互相矛盾。
- **学生预期**：「到底是谁？」「证据为什么会矛盾？」

### 深层钩子
- **内容**：为什么所有证据都「太完美了」？谁在幕后操控证据？小慧笔记本上的「教授」字样暗示了什么？展示柜碎片上的法袍一角属于谁？
- **学生预期**：「完美证据反而可疑？」「教授那句话是什么意思？」

### 教学关联
- 开场即暗示「精确描述」的重要性：三份证据的模糊描述导致矛盾，需要用定语从句精确重新定义
