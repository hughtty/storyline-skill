# 开场分镜脚本：圆圆的分身之谜

## 基本信息
- 时长：约 90 秒
- 场景：魔法厨房
- 出场角色：小智、圆圆
- 核心功能：引入困境 + 抛出钩子

## 分镜列表

### 镜头 01
- **景别**：全景
- **时长**：5s
- **运镜**：缓慢推近
- **画面**：
  一个充满魔法气息的厨房，锅碗瓢盆在空中漂浮，食材散发着光芒。厨房中央的操作台上，放着一个巨大的圆形蛋糕，蛋糕表面有星星点点的魔法光斑。
- **音效/配乐建议**：轻快、略带神秘的厨房主题音乐
- **旁白**："在魔法英语学院的厨房里，今天有一份特别的惊喜..."

## 钩子植入说明
- 抛出的悬念：蛋糕被施了分身魔法，只有理解"平均分"和"几分之一"才能分配蛋糕
- 与知识点的关联方式：分数的核心概念就是"平均分"——把一个整体分成若干相等部分，每部分就是几分之一。蛋糕作为圆形物体，天然适合展示分数（切蛋糕=分数）
- 学生观后预期：应该产生"怎么分？""什么是几分之一？""怎样才能吃到蛋糕？"的好奇心，并期待学习后能知道答案
