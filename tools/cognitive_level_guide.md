# 认知水平适配参考表

用于 story-outline 和 script-writer 等子技能，确保产出符合目标年级学生的认知特点。

## 低年级（1-2 年级 / 6-8 岁）

### 台词风格
- 短句为主，每句不超过 10 个字
- 大量使用语气词（"呀""呢""吧"）
- 直接表达情绪，不隐藏
- 重复强调关键信息

### 情节复杂度
- 单线叙事，无反转
- 因果关系明确直接（A 导致 B）
- 一个困难对应一个解决方案
- 无时间跳跃、无倒叙

### 人物关系
- 2-3 个角色，关系简单清晰
- 明确的"好"与"需要帮助"的角色
- 无复杂动机或隐藏意图

### 示例
```
角色A："这里好黑呀！"
角色B："别害怕，我有光！"
角色A："真的吗？太好了！"
```

## 中年级（3-4 年级 / 8-10 岁）

### 台词风格
- 适当使用复杂句式（复合句）
- 可包含简单的推理表达（"因为...所以...""如果...就..."）
- 允许角色有轻微的情绪掩饰

### 情节复杂度
- 单线叙事 + 1 个小障碍
- 需要简单的步骤分解（先 A 再 B 再 C）
- 可包含简单的意外（但很快解决）

### 人物关系
- 3-4 个角色，可有简单互动
- 角色有明确但简单的个人目标
- 允许角色之间有小矛盾（很快和解）

### 示例
```
角色A："门上有三把锁，我们得找到三把钥匙。"
角色B："可是第一把钥匙在哪呢？"
角色A："看，那边的石碑上有提示——它说'太阳升起的地方'..."
```

## 高年级（5-6 年级 / 10-12 岁）

### 台词风格
- 复杂句式自然流畅
- 可含隐喻、暗示
- 角色可以表达复杂情绪（矛盾、犹豫、决心）

### 情节复杂度
- 可有多线叙事（主线 + 一条支线）
- 允许 1-2 个反转
- 需要多步骤推理
- 可有轻微悬念

### 人物关系
- 4-5 个角色，关系可较复杂
- 角色可有隐藏动机或成长弧线
- 允许角色间有真正冲突（但最终解决）

### 示例
```
角色A："这三把锁不只是机关...它们是一种考验。"
角色B："你是说，有人在测试我们？"
角色A："或者说，在测试我们是否真正理解了'规律'的含义。"
```

## 初中（7-9 年级 / 12-15 岁）

### 台词风格
- 接近青少年口语，可含讽刺、幽默
- 复杂的逻辑推理表达
- 角色可讨论抽象概念

### 情节复杂度
- 多线叙事正常化
- 反转和悬念是常态
- 需要跨学科知识关联
- 可有开放式结尾或道德困境

### 人物关系
- 复杂的社会关系网络
- 角色成长弧线明显
- 允许灰色地带的道德选择

### 示例
```
角色A："规律从来都不是为了限制我们，而是为了让我们理解世界运行的方式。"
角色B："但如果规则本身就是错的呢？"
角色A："那我们就需要找到更好的规律——这就是学习的目的。"
```

## 快速判断

当未明确年级时，根据知识点难度自动判断：
- 基础概念（定义、简单规则）→ 低年级
- 应用型知识（计算、简单推理）→ 中年级
- 抽象概念（定理、公式推导）→ 高年级
- 综合分析（跨章节、多知识点融合）→ 初中
