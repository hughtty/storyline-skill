# 剧情设计模式库

## 钩子设计模式

### 模式 A：困境型钩子
角色遇到无法解决的困难，需要学习知识点才能克服。

**适用**：逻辑性强、有明确解题步骤的知识点
**示例**：门锁密码 = 语法规则；地图缺失 = 几何知识

### 模式 B：寻找型钩子
角色需要找到某样东西，线索藏在知识点中。

**适用**：词汇、概念类知识点
**示例**：寻找三个关键词 = 三个核心概念；拼出密码 = 单词拼写

### 模式 C：修复型钩子
某样东西坏了/失灵了，需要按照知识点规则修复。

**适用**：规则类、流程类知识点
**示例**：机器故障 = 运算规则错误；魔法失灵 = 语法错误

### 模式 D：竞争型钩子
角色需要赢得比赛/挑战，条件是掌握知识点。

**适用**：需要练习和熟练度的知识点
**示例**：答题闯关 = 口算练习；辩论胜利 = 语言表达

## 教学抓手模式

### 模式 1：钥匙模式
每个知识点 = 一把钥匙，集齐后开门

```
开场：角色被困在门前，门有 N 把锁
节点 1：学完知识点 1 → 获得钥匙 1 → 打开锁 1
节点 2：学完知识点 2 → 获得钥匙 2 → 打开锁 2
结尾：集齐所有钥匙 → 门开 → 通关
```

### 模式 2：拼图模式
每个知识点 = 一块拼图，拼完揭示答案

```
开场：角色发现一幅残缺的地图/密码
节点 1：学完知识点 1 → 获得拼图 1
节点 2：学完知识点 2 → 获得拼图 2
结尾：拼完所有拼图 → 揭示秘密 → 通关
```

### 模式 3：升级模式
角色能力逐步提升，每个知识点 = 一次升级

```
开场：角色面对强大敌人/困难，能力不够
节点 1：学完知识点 1 → 角色升级（获得新能力）
节点 2：学完知识点 2 → 再次升级
结尾：角色满级 → 战胜困难 → 通关
```

### 模式 4：破译模式
需要解码/翻译的信息，每个知识点 = 一条线索

```
开场：角色发现神秘信息/密文
节点 1：学完知识点 1 → 破译第一部分
节点 2：学完知识点 2 → 破译第二部分
结尾：完全破译 → 获得关键信息 → 通关
```

## 节点过渡模式

### 简单过渡（30 秒内）
```
角色A："看来我们需要先理解 [知识点名称]。"
[老师开始教学]
```

### 发现线索型
```
角色A：（发现新线索）"等等，这里有个提示！"
角色B："上面写着什么？"
角色A："它说...这和我们要学的 [知识点] 有关！"
[老师开始教学]
```

### 角色求助型
```
角色A：（遇到困难）"这个问题太难了..."
角色B："别担心，老师正要教我们解决它的方法！"
[老师开始教学]
```

### 练习反馈型（答对）
```
角色A：（兴奋）"太棒了！我们答对了！"
角色B："看，第一道锁打开了！"
[剧情推进]
```

### 练习反馈型（答错/需鼓励）
```
角色A："哎呀，好像不太对..."
角色B：（鼓励）"没关系，我们再想想。老师刚才教的方法，第一步是什么来着？"
[老师引导复习]
```

## 结尾收束模式

### 圆满型
```
角色A：（使用所学解决问题）"原来如此！根据 [知识点]，我们应该这样做！"
[困难解决，角色欢呼]
角色B："我们做到了！"
```

### 成长型
```
角色A：（回顾）"一开始我觉得 [知识点] 好难，但现在我明白了..."
[解决困难，角色有所感悟]
角色B："你进步了！"
```

### 预告型（非单元结束）
```
角色A：（解决当前困难）"终于解决了！"
角色B：（指向远方）"但看那边...似乎还有新的挑战在等着我们。"
角色A：（好奇）"那是什么？"
角色B："也许下节课，我们就会知道了..."
[悬念钩子]
```

### 闭环型（单元结束）
```
角色A：（如释重负）"这个单元的冒险终于结束了。"
角色B：（微笑）"但我们学到的知识，会一直陪伴着我们。"
[温馨收尾，无悬念]
```
